## Аналіз

У workflow на трьох API від 100 до 200 VUs RPS змінюється з 1362.56 до 1410.56, а p99 — з 213.29 до 486.84 мс. Це ознака насичення між цими ступенями: пропускна здатність майже вирівнюється, повільний хвіст різко зростає.
При 200 VUs середня затримка 138.45 мс приховує p99 486.84 мс. Черги запитів, конкуренція за CPU і підключення до БД можуть збільшувати хвіст непропорційно середньому.
Масштабування workflow при 200 VUs: 1415.56 RPS на одному API проти 1410.56 на трьох. Це вказує на спільний обмежувач поза кількістю API-вузлів; конкретний компонент слід підтвердити одночасними CPU/DB/k6 вимірюваннями.
