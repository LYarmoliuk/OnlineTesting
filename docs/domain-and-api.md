# Доменна модель та REST API

## 1. Призначення системи

OnlineTesting — вебплатформа для створення та керування онлайн-тестами. Система дає змогу створювати тести, додавати запитання та варіанти відповідей, визначати правильні відповіді й редагувати вміст тестів.

## 2. Доменна модель

### Test
- `Id` — унікальний ідентифікатор тесту.
- `Title` — назва тесту (обов'язкове поле, до 150 символів).
- `Description` — опис тесту (до 2000 символів).
- `IsPublished` — ознака публікації.
- `CreatedAt` — дата й час створення в UTC.
- `Questions` — колекція запитань тесту.

### Question
- `Id` — унікальний ідентифікатор запитання.
- `TestId` — ідентифікатор батьківського тесту.
- `Text` — текст запитання.
- `Order` — порядок відображення.
- `Points` — кількість балів.
- `AnswerOptions` — колекція варіантів відповіді.

### AnswerOption
- `Id` — унікальний ідентифікатор варіанта.
- `QuestionId` — ідентифікатор запитання.
- `Text` — текст варіанта відповіді.
- `IsCorrect` — ознака правильної відповіді.

## 3. Зв'язки

- Один тест (`Test`) може містити багато запитань (`Question`).
- Одне запитання може містити багато варіантів відповіді (`AnswerOption`).
- Видалення тесту каскадно видаляє його запитання та варіанти відповідей.
- Видалення запитання каскадно видаляє його варіанти відповідей.

## 4. REST API

Базова адреса локального API: `http://localhost:8080`.

| Метод | Endpoint | Призначення |
|---|---|---|
| GET | `/api/tests` | Отримати список тестів |
| GET | `/api/tests/{id}` | Отримати тест за ID |
| POST | `/api/tests` | Створити тест |
| PUT | `/api/tests/{id}` | Оновити тест |
| DELETE | `/api/tests/{id}` | Видалити тест |
| GET | `/api/tests/{testId}/questions` | Отримати запитання тесту |
| POST | `/api/tests/{testId}/questions` | Створити запитання |
| GET | `/api/questions/{id}` | Отримати запитання |
| PUT | `/api/questions/{id}` | Оновити запитання |
| DELETE | `/api/questions/{id}` | Видалити запитання |
| GET | `/api/questions/{questionId}/options` | Отримати варіанти відповіді |
| POST | `/api/questions/{questionId}/options` | Створити варіант відповіді |
| GET | `/api/options/{id}` | Отримати варіант відповіді |
| PUT | `/api/options/{id}` | Оновити варіант відповіді |
| DELETE | `/api/options/{id}` | Видалити варіант відповіді |

## 5. Технології

- Frontend: Vue 3, TypeScript, Vue Router, Pinia, Vite.
- Backend: ASP.NET Core Web API на .NET 10.
- Доступ до даних: Entity Framework Core.
- База даних: PostgreSQL.
- Документування API: Swagger / OpenAPI.
- Розгортання: Docker Compose.

## 6. Валідація та обмеження

Для назв, описів і текстів використовуються обмеження довжини. API використовує асинхронні операції з базою даних і повертає HTTP-статуси, зокрема 201 для створення, 204 для успішного видалення та 404, якщо ресурс не знайдено.

Поле `IsCorrect` призначене для керування правильними відповідями. Перед відкриттям API для студентів потрібно відокремити організаторські операції від студентських і не повертати правильні відповіді до завершення тестування. Авторизація та розмежування ролей потребують окремої реалізації.
